## Proyectos destacados

### Victus Residencias
Plataforma para gestión de conjuntos residenciales, con arquitectura hexagonal y microservicios, desplegada de forma automatizada con GitHub Actions. El sistema está dividido en varios repositorios:

| Servicio | Repositorio |
|---|---|
| Backend | [Backend_Victus_Residencias](https://github.com/TomasCGH/Backend_Victus_Residencias) |
| Frontend | [Front_end_victus](https://github.com/TomasCGH/Front_end_victus) |
| Message Service | [message_service_victus](https://github.com/TomasCGH/message_service_victus) |
| Parameter Service | [parameter_service_victus](https://github.com/TomasCGH/parameter_service_victus) |

### EatUpApi
Plataforma de gestión para aplicaciones de entrega y venta de alimentos, desarrollada en equipo (cada integrante a cargo de un módulo). Usa una arquitectura de microservicios comunicados de forma asíncrona con **RabbitMQ**, cubriendo catálogo de productos, pedidos, usuarios y entregas.

| Módulo | Repositorio |
|---|---|
| API principal (Gateway) | [EatUpApi](https://github.com/TomasCGH/EatUpApi) |
| Commercial Module | [Commercial_Module_EatUpApi](https://github.com/TomasCGH/Commercial_Module_EatUpApi) |

**Stack:** Java · Spring Boot · RabbitMQ · MySQL/PostgreSQL · Redis · Docker · JWT
